# المسار 1 · المرحلة 1.2 — رسم الخرائط وسير عمل الوكيل

## لماذا هذه المرحلة مهمة
لا يمكنك تقييم ما لم ترسم خريطته. الرسم المنهجي يقلل المعلمات والمسارات المخفية الفائتة.

## أهداف التعلم
- بناء خريطة موقع مجهول مقابل مصادق لتطبيق مختبر
- ضبط وكيل اعتراض **فقط** لحركة المختبر
- سرد المعلمات والأدوار المهمة

## نقطة تحقق السلامة
عنوان استماع الوكيل على واجهة محلية/مختبرية. النطاق محدود بأسماء/عناوين المختبر. عطّل الاعتراض عند تصفح مواقع غير ذات صلة.

## مفاهيم أساسية
- عقلية اكتشاف المحتوى (وليس القوة العمياء على الإنترنت)
- الزحف بحذر على تطبيقات مختبر هشة
- اعتراض ← فحص ← تمرير/إسقاط
- تعديل يدوي للأطلبات على أهداف المختبر

## تمرين
1. ثبّت/اضبط ZAP أو Burp Community للمختبر فقط
2. ارسم خريطة Juice Shop أو DVWA؛ صدّر خريطة موقع بسيطة
3. لاحظ المناطق التي تتطلب تسجيل دخول ومسارات الرفع أو الإدارة إن وُجدت

## مراجعة
- ما الفرق بين الرسم السلبي والاكتشاف النشط؟
- لماذا يجب تقييد نطاق الوكيل؟
