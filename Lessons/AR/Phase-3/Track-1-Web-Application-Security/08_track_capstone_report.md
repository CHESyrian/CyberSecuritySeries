# المسار 1 · المرحلة 1.8 — تقرير التقييم الختامي

## المخرج
تقييم كامل لـ**تطبيق مختبر واحد** مقصود:

1. النطاق وقواعد الاشتباك (المختبر فقط)
2. المنهجية (الرسم، الحسابات، الأدوات)
3. جدول النتائج (العنوان، منطق الخطورة، الأدلة، المعالجة)
4. ملاحظات إيجابية / نقاط قوة
5. خطة إعادة الاختبار
6. التنظيف (استعادة اللقطات)

## معيار الجودة
يجب أن يتمكن القارئ من إعادة خطواتك على نفس تطبيق المختبر وفهم المخاطر دون مبالغة.
