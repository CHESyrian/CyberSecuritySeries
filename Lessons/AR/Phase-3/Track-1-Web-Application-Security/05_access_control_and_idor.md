# المسار 1 · المرحلة 1.5 — التحكم في الوصول وIDOR

## أهداف التعلم
- شرح مشكلات الامتياز الرأسي مقابل الأفقي
- اختبار فحوصات معرف الكائن والدور **داخل تطبيق المختبر فقط**
- توثيق فجوات التفويض مع أدلة

## نقطة تحقق السلامة
استخدم حسابات المختبر فقط. لا تختبر التحكم في الوصول على SaaS طرف ثالث.

## تمرين
بمستخدمَي مختبر، حاول الوصول إلى كائن مستخدم آخر بتغيير المعرف في تطبيق تدريب يسمح بذلك. سجّل الطلب ورموز الاستجابة.

## مراجعة
- لماذا يجب فرض التفويض على جانب الخادم؟
