# المسار 1 · المرحلة 1.1 — HTTP والجلسات والمصادقة

## لماذا هذه المرحلة مهمة
يبدأ أمان الويب بفهم كيفية تبادل المتصفح والخادم للطلبات، والحفاظ على الحالة، وإثبات الهوية. ضعف الجلسة أو ملفات تعريف الارتباط يضعف معظم الضوابط اللاحقة.

## أهداف التعلم
- وصف طرق HTTP ورموز الحالة والترويسات ذات الصلة بالأمان
- شرح ملفات تعريف الارتباط والسمات: Secure وHttpOnly وSameSite
- مقارنة المصادقة الأساسية ومصادقة النموذج/الجلسة وأنماط الرموز على مستوى عالٍ
- التقاط وتوثيق تدفق تسجيل دخول عادي ضد تطبيق **مختبري** فقط

## نقطة تحقق السلامة
يجب أن يكون عنوان URL/IP الهدف تطبيقاً تدريبياً مقصوداً في مختبرك (DVWA أو Juice Shop وغيرها). لا تصادق على مواقع إنتاج أو طرف ثالث كجزء من هذا التمرين.

## مفاهيم أساسية
- **الطلب/الاستجابة:** الطريقة، المسار، الترويسات، الجسم، الحالة
- **الحالة:** HTTP عديم الحالة؛ الجلسات/ملفات تعريف الارتباط تعيد السياق
- **مخاطر الجلسة:** التثبيت، سرقة معرّف الجلسة، غياب المهلة
- **أعلام ملفات تعريف الارتباط:** تقليل التعرض لـ XSS (HttpOnly) والنص الواضح (Secure)

## تمرين (المختبر فقط)
1. تصفّح تطبيق المختبر مع فتح DevTools ← Network
2. سجّل الدخول بحساب **مختبري**؛ لاحظ Set-Cookie وإعادة التوجيه
3. سجّل ملفات تعريف الارتباط الظاهرة والأعلام المضبوطة
4. سجّل الخروج وتحقق من إبطال الجلسة إن وُجد
