# المرحلة 0 · وحدات الأساس

توفر هذه الوحدات الأساسيات الضرورية للمبتدئين تمامًا قبل دراسة المنهج الرئيسي للأمن السيبراني (المراحل 1–9).

كل المحتوى مفاهيمي ومناسب للمبتدئين. لا تُدرج أي تعليمات هجومية قابلة للتنفيذ.
