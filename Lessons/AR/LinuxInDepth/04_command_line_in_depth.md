# 04 — سطر الأوامر بعمق

## مقدمة

الصدفة هي الواجهة الأساسية للعمل الجاد على Linux. تتجاوز هذه الوحدة التنقل الأساسي وتشرح كيف تحلّل الصدفة الأوامر، وتوسّع الكلمات، وتتعامل مع الإدخال/الإخراج، وتدير المهام، وتعرض البيئة. كما تغطي مجموعة عملية من الأدوات التي تظهر باستمرار في عمل الأمن وإدارة الأنظمة — كل منها مع الصيغة والخيارات المهمة والسلوك المتوقع.

إتقان هذه الآليات يحوّل الطرفية من مكان تكتب فيه أوامر فردية إلى بيئة قابلة للبرمجة.

---

## أهداف التعلم

بنهاية هذه الوحدة ستكون قادرًا على:

- شرح الفرق بين أمر مدمج في الصدفة وأمر خارجي
- التنبؤ بكيفية أداء الصدفة للتوسيع (globs، المتغيرات، استبدال الأوامر، الحساب)
- إعادة توجيه التدفقات القياسية وبناء الأنابيب
- التحكم في المهام والعمليات الخلفية
- فحص البيئة وتعديلها
- استخدام أدوات التنقل والبحث ومعالجة النصوص والعمليات والشبكة والنظام مع فهم الغرض والخيارات الشائعة
- كتابة أسطر أوامر صغيرة وآمنة وسكربتات بسيطة تتصرف بشكل متوقع

## المفاهيم الأساسية

### 1. ماذا تفعل الصدفة

عندما تكتب سطرًا وتضغط Enter تقوم الصدفة بـ:

1. قراءة السطر.
2. تقسيمه إلى رموز (كلمات وعوامل).
3. أداء التوسيعات (انظر أدناه).
4. تطبيق إعادة التوجيه.
5. تحديد موقع الأمر (مدمج، دالة، أو تنفيذي على `PATH`).
6. تنفيذه، مع ربط الأنابيب إن وُجدت.
7. الانتظار (أو عدمه) للانتهاء والإبلاغ عن حالة الخروج.

أصداف تفاعلية شائعة: **bash**، **zsh**، **fish**. معظم السكربتات والأمثلة في هذا المنهج تفترض صدفة موجّهة لـ POSIX (bash أو dash).

### 2. المدمج مقابل الأوامر الخارجية

- **مدمج (built-in)** — منفَّذ داخل الصدفة نفسها (`cd`، `export`، `read`، `ulimit`، …). لا تُبدأ عملية منفصلة.
- **خارجي** — ملف تنفيذي يُوجد عبر `$PATH` (`ls`، `grep`، `find`، `ps`، …).

```bash
type cd                 # builtin
type ls                 # خارجي (مسار مخزّن)
type echo               # غالبًا مدمج
which ls                # المسار الكامل للأمر الخارجي
command -v ls           # طريقة محمولة لحل أمر
command -v cd           # يُظهر أن "cd" مدمج في الصدفة
```

**لماذا يهم:** الأوامر المدمجة يمكنها تغيير حالة الصدفة نفسها (`cd` يغيّر دليل العمل لعملية الصدفة). الأوامر الخارجية تعمل كعمليات ابن ولا يمكنها تغيير دليل العمل أو متغيرات الأب بشكل دائم إلا عبر تراكيب مثل `export` أو استبدال الأوامر عمدًا.

### 3. التوسيع (الترتيب مهم)

تؤدي الصدفة عدة أنواع من التوسيع قبل تنفيذ الأمر. ترتيب عملي مبسّط:

1. توسيع الأقواس — `{a,b,c}`، `{1..5}`
2. توسيع التلدة — `~`، `~alice`
3. توسيع المعامل / المتغير — `$VAR`، `${VAR}`
4. التوسيع الحسابي — `$(( ... ))`
5. استبدال الأوامر — `$( ... )` أو `` `...` ``
6. تقسيم الكلمات (على `$IFS`)
7. توسيع اسم المسار (globs) — `*`، `?`، `[abc]`

```bash
echo {one,two,three}              # أقواس → one two three
echo ~/Documents                  # تلدة → /home/you/Documents
NAME=alice; echo "Hello $NAME"    # توسيع معامل
echo $(( 2 + 3 * 4 ))             # حسابي → 14
echo "Today is $(date +%Y-%m-%d)" # استبدال أوامر
echo /usr/bin/py*                 # توسيع مسار (globs)
```

تغيّر علامات الاقتباس السلوك:

- علامات مزدوجة `"..."` — تسمح بتوسيع المعامل والحساب واستبدال الأوامر؛ تكبح تقسيم الكلمات والـ globs.
- علامات مفردة `'...'` — لا توسيع على الإطلاق.
- بدون اقتباس — توسيع كامل وتقسيم كلمات.

```bash
VAR="a b c"
echo $VAR          # ثلاث كلمات (تقسيم كلمات)
echo "$VAR"        # كلمة واحدة
echo '$VAR'        # أحرف حرفية $ V A R
```

**ملاحظة أمنية:** المتغيرات غير المقتبسة التي تتوسع إلى فراغ أو إلى قيم تحتوي مسافات/globs مصدر متكرر للأخطاء، وفي السكربتات التي تستدعي `rm` أو ما شابه، لسلوك خطير. فضّل `"$VAR"` ما لم تقصد التقسيم عمدًا.

### 4. التدفقات القياسية وإعادة التوجيه

لكل عملية ثلاثة تدفقات قياسية:

| واصف الملف | الاسم | الاتصال الافتراضي |
|------------|-------|-------------------|
| 0 | stdin | لوحة المفاتيح |
| 1 | stdout | الطرفية |
| 2 | stderr | الطرفية |

عوامل إعادة التوجيه:

```bash
command > file          # stdout إلى ملف (اقتطاع المحتوى الموجود)
command >> file         # إلحاق stdout
command 2> file         # stderr إلى ملف
command &> file         # stdout وstderr معًا (bash)
command > file 2>&1     # stderr يتبع stdout (شكل محمول)
command < file          # stdin من ملف
command << EOF          # here-document (stdin من الأسطر التالية حتى EOF)
سطر1
سطر2
EOF
command <<< "نص"        # here-string (bash) — stdin من سلسلة
```

**الترتيب مهم لـ `2>&1`:**  
`command > file 2>&1` يرسل كلا التدفقين إلى `file`.  
`command 2>&1 > file` يوجّه stderr أولاً إلى stdout الحالي (عادة الطرفية)، ثم يعيد توجيه stdout إلى `file` — فيبقى stderr على الطرفية.

### 5. الأنابيب

يربط الأنبوب stdout لأمر بـ stdin للأمر التالي:

```bash
command1 | command2 | command3
```

حالة خروج الأنبوب عادة حالة الأمر **الأخير**. في bash، `set -o pipefail` يجعل الأنبوب يفشل إذا فشل **أي** مرحلة — موصى به في السكربتات.

```bash
set -o pipefail
false | true
echo $?                 # 1 عندما يكون pipefail مفعّلاً؛ 0 عندما يكون معطّلاً
```

### 6. حالة الخروج

كل أمر يعيد حالة خروج رقمية (0–255):

- `0` — نجاح
- غير صفر — فشل (بالاصطلاح)

```bash
ls /tmp
echo $?                 # 0 إذا وُجد /tmp وكان قابلاً للسرد

ls /nonexistent
echo $?                 # غير صفر (غالبًا 2)

false
echo $?                 # 1
```

في السكربتات تختبر الحالة بـ `if` و`&&` و`||` و`set -e` (الخروج عند أول فشل).

```bash
command1 && command2    # نفّذ command2 فقط إذا نجح command1
command1 || command2    # نفّذ command2 فقط إذا فشل command1
```

### 7. التحكم في المهام

```bash
long_command &          # ابدأ في الخلفية؛ تطبع الصدفة رقم المهمة وPID
jobs                    # سرد مهام الخلفية/المتوقفة لهذه الصدفة
jobs -l                 # تضمين PIDs
fg %1                   # جلب المهمة 1 إلى المقدمة
bg %1                   # استئناف المهمة المتوقفة 1 في الخلفية
Ctrl-Z                  # تعليق (إيقاف) المهمة الحالية في المقدمة
kill %1                 # إرسال SIGTERM للمهمة 1
kill -9 %1              # SIGKILL (ملاذ أخير)
wait %1                 # انتظار انتهاء المهمة 1
```

أرقام المهام (`%1`، `%2`، …) لكل صدفة. معرّفات العمليات (PIDs) على مستوى النظام.

### 8. البيئة

ترث العملية مجموعة من أزواج اسم=قيمة تُسمى البيئة.

```bash
printenv                # كل متغيرات البيئة
printenv PATH           # متغير واحد
echo $PATH
echo $HOME
echo $USER
export MYVAR=value      # إنشاء/تحديث ووضع علامة للتصدير للأبناء
env MYVAR=temp cmd      # تشغيل cmd بتغيير بيئة لمرة واحدة
unset MYVAR             # إزالة من الصدفة
```

متغيرات مهمة:

| المتغير | الغرض النموذجي |
|---------|----------------|
| `PATH` | أدلة البحث عن التنفيذيات (الترتيب مهم) |
| `HOME` | دليل منزل المستخدم |
| `USER` / `LOGNAME` | اسم المستخدم |
| `SHELL` | صدفة تسجيل الدخول |
| `PWD` | دليل العمل الحالي |
| `OLDPWD` | دليل العمل السابق (يستخدمه `cd -`) |
| `IFS` | فاصل الحقول الداخلي (تقسيم الكلمات) |
| `EDITOR` / `VISUAL` | محرر النصوص المفضّل |
| `LANG` / `LC_*` | اللغة وترميز الأحرف |

**أمن PATH:** تُبحث الأدلة الأسبق في `PATH` أولاً. دليل قابل للكتابة مبكرًا في `PATH` (أو `.` في `PATH`) خطر كلاسيكي لتصعيد الامتياز والاختطاف. فضّل المسارات المطلقة في السكربتات الحرجة عندما تكون القابلية للتنبؤ مهمة.

## أوامر أساسية — مرجع تفصيلي

كل قسم فرعي يسرد الأمر، وما يفعله، وخيارات مهمة، ومثال استخدام قصير مع المعنى المتوقع.

### التنقل وفحص الأدلة

#### `pwd` — طباعة دليل العمل

```bash
pwd                     # المسار المطلق للدليل الحالي
pwd -P                  # حل الروابط الرمزية (المسار الفيزيائي)
```

يُظهر أين أنت. السكربتات غالبًا تلتقطه: `BASE=$(pwd)`.

#### `cd` — تغيير الدليل

```bash
cd /var/log             # مسار مطلق
cd ../..                # نسبي: صعود مستويين
cd                      # الانتقال إلى $HOME
cd -                    # الانتقال إلى الدليل السابق ($OLDPWD)
cd ~alice               # منزل alice (إن سُمح)
```

مدمج؛ يغيّر دليل العمل الحالي للصدفة. `cd` إلى مسار غير موجود يفشل ويتركك حيث كنت.

#### `ls` — سرد محتويات الدليل

```bash
ls                      # أسماء فقط
ls -l                   # تنسيق طويل: النوع، الصلاحيات، الروابط، المالك، المجموعة، الحجم، الوقت، الاسم
ls -la                  # تضمين الملفات المخفية (النقطية)
ls -lhrt                # طويل، أحجام بشرية، وقت عكسي (الأحدث آخرًا) — مفيد للسجلات
ls -ld /etc             # سرد الدليل نفسه وليس محتوياته
ls -li                  # تضمين أرقام الـ inode
ls -R                   # تكراري (قد يكون ضخمًا)
ls --color=auto         # تلوين (غالبًا اسم مستعار)
```

**أعمدة التنسيق الطويل (مبسّط):**  
نوع+صلاحيات | عدد الروابط | المالك | المجموعة | الحجم | mtime | الاسم

لا **تحلّل** مخرجات `ls` في السكربتات؛ استخدم `find` أو `stat` أو globs الصدفة بدلًا من ذلك.

#### `file` — تحديد نوع الملف

```bash
file /etc/passwd        # "ASCII text"
file /bin/ls            # ELF executable, …
file -b filename        # مختصر (بدون بادئة اسم الملف)
file -i filename        # نوع MIME
```

يستخدم أرقامًا سحرية وتخمينات المحتوى، وليس الامتداد فقط. مفيد عند التحقيق في ثنائيات أو ملفات بيانات مجهولة.

#### `stat` — بيانات وصفية تفصيلية

```bash
stat filename
stat -c '%n %a %U %G %s' filename   # تنسيق مخصص: الاسم، الوضع، المستخدم، المجموعة، الحجم
stat -c '%Y' filename               # mtime كثوانٍ epoch
```

يعرض الـ inode، الحجم، الكتل، النوع، الجهاز، الروابط، أوقات الوصول/التعديل/التغيير، والصلاحيات بأشكال متعددة. مفضّل على تحليل `ls` عندما تحتاج حقولًا موثوقة.

#### `tree` — شجرة الدليل (إن وُجدت)

```bash
tree -L 2               # عمق 2
tree -a -L 2            # تضمين المخفي
tree -d -L 3            # أدلة فقط
tree -h /var/log        # أحجام بشرية
```

ليست مثبتة دائمًا افتراضيًا؛ ثبّتها عبر مدير الحزم في المختبر إن لزم.

#### `realpath` / `readlink` — حل المسارات

```bash
realpath filename       # مسار مطلق مع حل الروابط الرمزية
readlink -f filename    # مشابه (GNU)
readlink symlink        # عرض هدف الرابط الرمزي المباشر فقط
```

أساسي عندما يجب أن تعمل السكربتات بمسارات قانونية.

### البحث عن الملفات والأوامر

#### `find` — البحث في نظام الملفات

```bash
find /path -name '*.log'                # مطابقة الاسم (أسلوب صدفة، اقتبس النمط)
find /path -iname '*.log'               # غير حسّاس لحالة الأحرف
find /path -type f                      # ملفات عادية فقط
find /path -type d                      # أدلة فقط
find /path -mtime -7                    # عُدّل في آخر 7 أيام
find /path -mtime +30                   # عُدّل منذ أكثر من 30 يومًا
find /path -size +10M                   # أكبر من 10 ميبيبايت
find /path -user alice                  # يملكه alice
find /path -perm -4000                  # بت setuid مضبوط
find /path -perm 644                    # وضع مطابق تمامًا
find /path -name '*.conf' -exec cp {} /backup/ \;
find /path -name '*.tmp' -delete        # حذر: حذف دائم
```

**مهم:**

- أنماط `-name` تُطابق مقابل الاسم الأساسي؛ اقتبسها حتى لا توسّعها الصدفة قبل أن يراها `find`.
- `-exec cmd {} \;` يشغّل `cmd` مرة لكل ملف؛ `-exec cmd {} +` يجمّع الملفات (أكثر كفاءة).
- فضّل `-print0` مع `xargs -0` عندما قد تحتوي الأسماء على مسافات أو أسطر جديدة.

```bash
find /var/log -name '*.log' -print0 | xargs -0 grep -l 'error'
```

#### `locate` — بحث سريع في قاعدة بيانات الأسماء

```bash
locate passwd
locate -i '*.conf'                  # غير حسّاس لحالة الأحرف
locate -r '/etc/.*\.conf$'          # تعبير نمطي
```

يستخدم قاعدة بيانات مبنية مسبقًا (`updatedb`). سريع جدًا، لكنه قد يكون قديمًا وعادة لا يرى الملفات المنشأة بعد آخر تحديث للقاعدة. ليس بديلاً عن `find` عندما تحتاج نتائج حية أو بحثًا واعيًا بالصلاحيات.

#### `which` / `type` / `command` — تحديد موقع أمر

```bash
which ls                    # مسار التنفيذي الخارجي (قد يفوت المدمجات/الأسماء المستعارة)
type ls                     # يبلّغ عن اسم مستعار أو مدمج أو ملف
type -a ls                  # كل المطابقات
command -v ls               # حل محمول
```

فضّل `type` أو `command -v` في السكربتات عندما تحتاج معرفة كيف ستحل الصدفة اسمًا.

#### `whereis` — مواقع الثنائي والمصدر وصفحة الدليل

```bash
whereis ls
whereis -b python3          # ثنائيات فقط
```

### العرض ومعالجة النصوص

#### `cat` — دمج وطباعة

```bash
cat file
cat file1 file2             # دمج
cat -n file                 # ترقيم كل الأسطر
cat -A file                 # إظهار الأحرف غير القابلة للطباعة
```

مناسب للملفات القصيرة. للملفات الكبيرة فضّل `less` أو `tail`.

#### `less` / `more` — صفحات

```bash
less file
less +F file                # وضع متابعة (مثل tail -f)؛ Ctrl-C ثم q للخروج
less -N file                # أرقام الأسطر
```

داخل `less`: `/pattern` بحث للأمام، `n` المطابقة التالية، `q` خروج، `h` مساعدة.

#### `head` / `tail` — أول / آخر أسطر

```bash
head file                   # أول 10 أسطر
head -n 20 file
tail file                   # آخر 10 أسطر
tail -n 50 file
tail -f /var/log/syslog     # متابعة (إلحاق حي)
tail -F /var/log/app.log    # متابعة وإعادة المحاولة إذا دُوِّر الملف
tail -n +5 file             # من السطر 5 حتى النهاية
```

`tail -f` / `journalctl -f` معيار لمراقبة السجلات الحية.

#### `wc` — عد الأسطر والكلمات والبايتات

```bash
wc file
wc -l file                  # أسطر فقط
wc -l file1 file2           # لكل ملف والإجمالي
wc -c file                  # بايتات
```

#### `grep` — طباعة الأسطر المطابقة لنمط

```bash
grep pattern file
grep -n pattern file        # مع أرقام الأسطر
grep -i pattern file        # غير حسّاس لحالة الأحرف
grep -v pattern file        # عكس (أسطر غير مطابقة)
grep -E 'pat1|pat2' file    # تعبير نمطي موسّع
grep -R pattern dir         # تكراري
grep -R --include='*.conf' pattern /etc
grep -l pattern files...    # طباعة أسماء الملفات المطابقة فقط
grep -c pattern file        # عدد الأسطر المطابقة
grep -A2 -B2 pattern file   # سياق: سطران بعد/قبل
```

حالة الخروج: 0 إن وُجدت أي مطابقة، 1 إن لم توجد، 2 عند خطأ. مفيد في السكربتات:

```bash
if grep -q 'ERROR' /var/log/app.log; then
  echo "وُجدت أخطاء"
fi
```

#### `cut` — إزالة أقسام من الأسطر

```bash
cut -d: -f1 /etc/passwd                 # الحقل الأول، فاصل نقطتين
cut -d: -f1,7 /etc/passwd               # الحقلان 1 و7
cut -d: -f1-3 /etc/passwd               # الحقول 1 إلى 3
cut -c1-10 file                         # الأحرف 1–10
```

أفضل للبيانات البسيطة المفصولة بفاصل. لمنطق حقول أكثر تعقيدًا استخدم `awk`.

#### `awk` — مسح الأنماط والمعالجة

```bash
awk -F: '{print $1, $7}' /etc/passwd    # مفصول بنقطتين؛ طباعة الحقلين 1 و7
awk '/error/ {print $0}' file           # أسطر تطابق تعبيرًا نمطيًا
awk '{sum += $1} END {print sum}' nums  # مجموع العمود الأول
awk -F, 'NR>1 {print $2}' data.csv      # تخطي الترويسة، طباعة العمود 2
```

`NR` رقم السجل (السطر) الحالي؛ `NF` عدد الحقول؛ `$0` السطر كله؛ `$1`…`$n` الحقول.

#### `sed` — محرر تدفق

```bash
sed 's/old/new/' file                   # استبدال أول حدوث لكل سطر
sed 's/old/new/g' file                  # استبدال الكل في كل سطر
sed -n '10,20p' file                    # طباعة الأسطر 10–20
sed -i 's/old/new/g' file               # تحرير في المكان (بحذر؛ انسخ احتياطيًا أولاً)
sed '/^#/d' file                        # حذف أسطر التعليق
```

`sed` قوي؛ ابدأ بالاستبدال واختيار الأسطر قبل كتابة سكربتات معقدة.

#### `sort` / `uniq` — ترتيب والإبلاغ عن التكرارات

```bash
sort file
sort -n file                            # ترتيب رقمي
sort -r file                            # عكسي
sort -k2 file                           # ترتيب حسب الحقل 2
sort -t: -k3n /etc/passwd               # فاصل نقطتين، حقل 3 رقمي
sort file | uniq                        # أسطر فريدة (يجب أن يكون الإدخال مرتبًا)
sort file | uniq -c                     # عد الحدوثات
sort file | uniq -c | sort -nr          # ترتيب حسب التكرار
```

أنبوب ترتيب كلاسيكي:

```bash
cut -d: -f7 /etc/passwd | sort | uniq -c | sort -nr
```

#### `xargs` — بناء أسطر أوامر من stdin

```bash
find . -name '*.tmp' -print0 | xargs -0 rm -f
echo 'a b c' | xargs -n 1 echo          # وسيط واحد لكل أمر
cat urls.txt | xargs -n1 curl -I        # بحذر، في المختبر فقط
```

زوج `-0` / `-print0` يتعامل مع أسماء ملفات تعسفية بأمان. بدون `-0`، المسافات في الأسماء تكسر الوسائط.

### العمليات والموارد

#### `ps` — لقطة للعمليات

```bash
ps                      # عمليات الطرفية الحالية
ps aux                  # كل العمليات، أعمدة بأسلوب BSD
ps -ef                  # كل العمليات، أسلوب System V
ps -u alice             # عمليات المستخدم alice
ps -p 1234              # PID محدد
ps -o pid,user,cmd -C sshd   # أعمدة مخصصة لعمليات اسمها sshd
```

أعمدة `ps aux` الشائعة: USER، PID، %CPU، %MEM، VSZ، RSS، TTY، STAT، START، TIME، COMMAND.

رموز STAT (اختيار): `R` تعمل، `S` نائمة، `D` غير قابلة للمقاطعة، `Z` زومبي، `T` متوقفة، `+` مجموعة عمليات المقدمة.

#### `top` / `htop` — عارض عمليات تفاعلي

```bash
top                     # اضغط q للخروج، h للمساعدة
htop                    # واجهة محسّنة إن وُجدت
```

مفيد لرصد مستهلكي CPU أو الذاكرة في الوقت الفعلي. يتيح `htop` بحثًا أسهل وعرض شجرة.

#### `pgrep` / `pkill` — إيجاد أو إرسال إشارة بالاسم

```bash
pgrep ssh               # PIDs مطابقة للاسم
pgrep -a ssh            # PIDs وسطر الأوامر الكامل
pgrep -u alice          # عمليات المستخدم
pkill -HUP nginx        # إرسال SIGHUP للعمليات المطابقة
pkill -u alice processname
```

أكثر أمانًا من تحليل مخرجات `ps` للاختيار البسيط بالاسم.

#### `kill` / `killall` — إرسال إشارات

```bash
kill 1234               # SIGTERM (افتراضي) — طلب مهذب للخروج
kill -15 1234           # نفس الشيء
kill -HUP 1234          # SIGHUP — غالبًا «إعادة تحميل الإعداد»
kill -9 1234            # SIGKILL — إجبار؛ العملية لا يمكنها التقاطه
kill -l                 # سرد أسماء الإشارات
killall processname     # بالاسم (استخدم بحذر)
```

فضّل SIGTERM أولاً؛ استخدم SIGKILL فقط عندما لا تستجيب العملية.

#### `lsof` — سرد الملفات المفتوحة (إن وُجد)

```bash
lsof -i                 # مقابس إنترنت (شبكة)
lsof -i :22             # أي شيء على المنفذ 22
lsof -u alice           # ملفات فتحها المستخدم
lsof /var/log/syslog    # من يفتح هذا الملف
lsof -p 1234            # ملفات فتحتها PID
```

مفيد جدًا لأسئلة «أي عملية تستخدم هذا المنفذ/الملف؟».

#### `ss` — إحصائيات المقابس (بديل حديث لكثير من netstat)

```bash
ss -tuln                # مقابس TCP/UDP مستمعة، رقمي
ss -tulpn               # تضمين معلومات العملية (قد يحتاج root)
ss -tan                 # كل TCP، رقمي
ss -tp                  # TCP مع العمليات
ss -s                   # إحصائيات ملخصة
ss dst 192.0.2.10       # تصفية حسب الوجهة
```

تشمل الحالات `LISTEN`، `ESTAB`، `TIME-WAIT`، إلخ. فضّل `ss` على `netstat` في Linux الحديث.

### الشبكة (أدوات المضيف الأساسية)

#### `ip` — عرض / التلاعب بالواجهات والعناوين والمسارات

```bash
ip link show            # الواجهات والحالة
ip -br link             # مختصر
ip addr show            # العناوين
ip -br addr
ip route show           # جدول التوجيه
ip route get 8.8.8.8    # أي مسار سيُستخدم
```

يستبدل كثيرًا من أدوات `ifconfig` / `route` الأقدم.

#### `ping` — صدى ICMP

```bash
ping -c 4 host          # أربع محاولات ثم توقف
ping -c 3 -W 2 host     # مهلة لكل محاولة
```

يفحص قابلية الوصول الأساسية وزمن الاستجابة. قد تحجبه بعض جدران النار.

#### `curl` — نقل البيانات (HTTP والمزيد)

```bash
curl -I https://example.com          # ترويسات فقط (شبيه بـ HEAD)
curl -v https://example.com          # مفصّل (تفاصيل الطلب/الاستجابة)
curl -o file https://example.com     # حفظ الجسم في ملف
curl -f -sS https://example.com      # فشل عند أخطاء HTTP، صامت لكن يُظهر الأخطاء
curl -X POST -H 'Content-Type: application/json' -d '{"a":1}' https://httpbin.org/post
```

أساسي لاستكشاف أخطاء API والويب. فضّل `curl -v` عند تشخيص TLS أو إعادة التوجيه.

#### `dig` / `host` — استعلام DNS

```bash
dig example.com
dig +short example.com
dig @8.8.8.8 example.com A
dig -x 8.8.8.8                       # بحث عكسي
host example.com
```

يُفضَّل `dig` لعمل DNS التفصيلي؛ `+trace` يسير في التسلسل الهرمي من الجذر.

#### `nc` (netcat) — اتصالات TCP/UDP تعسفية (استخدام المختبر)

```bash
nc -zv host 22                       # فحص اتصال (بدون إدخال/إخراج)
nc -l -p 12345                       # استماع (المختبر فقط)
```

قوي؛ قيّده بشبكات المختبر المصرح بها.

## شرح تفصيلي — سطر أوامر كامل

اعتبر:

```bash
find /var/log -name '*.log' -mtime -1 2>/dev/null | xargs grep -l 'error' | head
```

ما يحدث خطوة بخطوة:

1. **`find /var/log -name '*.log' -mtime -1`**  
   يمشي في `/var/log`، ويختار المسارات التي يطابق **اسمها الأساسي** `*.log` ووقت تعديلها خلال آخر 24 ساعة. النمط مقتبس حتى لا توسّعه الصدفة قبل أن يراه `find`.

2. **`2>/dev/null`**  
   يتجاهل رسائل الخطأ (مثل رفض الصلاحية على بعض الأدلة الفرعية). مفيد لمخرجات أنظف؛ في التحقيقات قد تريد الاحتفاظ بتلك الأخطاء أو تسجيلها.

3. **`| xargs grep -l 'error'`**  
   يأخذ قائمة المسارات من stdin ويشغّل `grep -l 'error'` عليها (ربما على دفعات). `-l` يطبع فقط أسماء الملفات التي تحتوي مطابقة واحدة على الأقل، وليس الأسطر المطابقة.

4. **`| head`**  
   يحدّ المخرجات إلى أول 10 أسطر (افتراضي) حتى لا تغمر مجموعة نتائج كبيرة الطرفية.

فهم كل جزء يتيح لك تعديل الأنبوب بأمان — مثل إضافة `-print0` / `xargs -0` لأسماء غير عادية، أو استبدال `head` بـ `wc -l` لعد الملفات المطابقة.

## أمثلة عملية

### ملفات مؤقتة آمنة والتنظيف

```bash
TMP=$(mktemp)
echo "work data" > "$TMP"
# ... استخدم "$TMP" ...
rm -f -- "$TMP"
```

ينشئ `mktemp` ملفًا فريدًا بصلاحيات آمنة. اقتبس دائمًا وفضّل `--` قبل مسارات المتغيرات عند استدعاء `rm`.

### ترتيب أصداف تسجيل الدخول

```bash
cut -d: -f7 /etc/passwd | sort | uniq -c | sort -nr
```

### متابعة سجل حي

```bash
tail -F /var/log/syslog
# أو على أنظمة systemd:
journalctl -f -u sshd
```

### فحص العمليات دون grep هش

```bash
pgrep -a ssh
ps -o pid,user,cmd -C sshd
```

### ما يستمع

```bash
ss -tulpn
sudo ss -tulpn | grep ':22'
```

### أكبر العناصر تحت /var

```bash
sudo du -xh --max-depth=1 /var 2>/dev/null | sort -hr | head
```

## أخطاء شائعة

| الخطأ | النتيجة | نهج أفضل |
|-------|---------|----------|
| متغيرات غير مقتبسة تحتوي مسافات | تقسيم الكلمات يكسر الأمر | اقتبس دائمًا: `"$VAR"` |
| `rm -rf $DIR` عندما يكون `DIR` فارغًا أو خاطئًا | قد يتوسع بشكل خطير | اقتبس؛ استخدم `rm -rf -- "$DIR"`؛ اختبر بـ `echo` أولاً |
| تجاهل حالة الخروج في السكربتات | إخفاقات صامتة | `set -euo pipefail` قرب أعلى السكربتات |
| تحليل مخرجات `ls` | هش مع الأحرف الخاصة | استخدم `find`، `stat`، globs، أو مكتبات مناسبة |
| تشغيل أنابيب كاملة كـ root | امتياز غير ضروري | ارفع فقط الأوامر التي تحتاجه |
| نسيان أن `>` يقتطع | فقدان بيانات عرضي | استخدم `>>` للإلحاق، أو أكّد الهدف |
| `find … -name *.log` دون اقتباس | توسّع الصدفة الـ glob مبكرًا | اقتبس الأنماط دائمًا: `-name '*.log'` |
| استخدام `kill -9` أولاً | لا فرصة لإغلاق نظيف | جرّب SIGTERM (الافتراضي) أولاً |

## أفضل الممارسات

- اقتبس المتغيرات واستبدالات الأوامر ما لم تقصد تقسيم الكلمات عمدًا.
- فضّل الخيارات الطويلة في السكربتات (`--recursive` بدل `-R`) للقابلية للقراءة عندما تتوفر.
- استخدم `set -euo pipefail` في سكربتات bash كافتراضي معقول، ثم أرْخِ انتقائيًا.
- افصل الاستكشاف التفاعلي عن سكربتات الإنتاج؛ اختبر السكربتات على بيانات غير حرجة.
- تعلّم `man` و`--help`؛ أسرع من البحث على الويب لأسئلة الأعلام الأساسية.
- ابنِ الأنابيب تدريجيًا: شغّل المرحلة الأولى، ثم أضف التالية، وافحص المخرجات كل مرة.
- فضّل `ss` على `netstat`، و`ip` على `ifconfig`، و`pgrep` على `ps | grep` للوضوح والمتانة.
- عامل أسماء الملفات كبايتات تعسفية: استخدم `-print0` / `xargs -0` أو `find -exec` عند تمرير مسارات كثيرة.

## تمرين عملي

1. أظهر الفرق بين المتغيرات غير المقتبسة والمقتبسة مزدوجًا والمقتبسة مفردًا التي تحتوي مسافات.
2. اكتب أنبوبًا يسرد أكبر خمسة أدلة تحت `/var` (تلميح: `du` + `sort` + `head`).
3. استخدم `find` لتحديد الملفات تحت دليل منزلك المعدّلة في آخر 24 ساعة؛ ثم حدّ القائمة بـ `head`.
4. ابدأ أمرًا طويل التشغيل في الخلفية (`sleep 300 &`)، اسرد المهام، اجلبه إلى المقدمة، علّقه بـ Ctrl-Z، استأنفه في الخلفية، ثم اقتله.
5. افحص `PATH` واشرح لماذا ترتيب الأدلة مهم للأمن والقابلية للتنبؤ.
6. استخدم `ss -tulpn` وحدّد خدمتين مستمعتين على الأقل وPIDs الخاصة بهما (إن ظهرت).
7. ابنِ أنبوبًا بـ `cut` و`sort` و`uniq -c` و`sort -nr` على `/etc/passwd` لترتيب الأصداف أو UIDs.

## أسئلة المراجعة

1. ما الفرق بين أمر مدمج في الصدفة وأمر خارجي؟ كيف تعرف أيهما `cd`؟
2. لماذا ينتج `echo $VAR` أحيانًا كلمات متعددة بينما ينتج `echo "$VAR"` واحدة؟
3. ماذا تمثل الأرقام 0 و1 و2 في سياق إعادة التوجيه؟
4. كيف تعيد توجيه stdout وstderr معًا إلى نفس الملف؟
5. أي حالة خروج تدل اصطلاحًا على النجاح؟
6. ماذا يفعل `Ctrl-Z` بعملية المقدمة؟
7. لماذا يُعتبر تحليل مخرجات `ls` ممارسة سيئة؟
8. ما الفرق بين `find … -name *.log` و`find … -name '*.log'`؟
9. متى تختار `pgrep -a name` على `ps aux | grep name`؟
10. لماذا قد يُظهر `df -h` مساحة حرة بينما يفشل إنشاء ملف بـ «No space left on device»؟

## ملخص

- الصدفة بيئة برمجة تؤدي التوسيع وإعادة التوجيه والتحكم في المهام قبل تنفيذ الأوامر.
- فهم التوسيع والاقتباس يمنع فئة كاملة من الأخطاء ومشاكل الأمن.
- الأنابيب وإعادة التوجيه تتيحان تكوين أدوات صغيرة في أسطر أوامر وسكربتات قوية.
- حالة الخروج والتحكم في المهام والبيئة أساسية للأتمتة الموثوقة.
- مفردات أوامر متينة — `find`، `grep`، `awk`، `sed`، `ps`/`pgrep`، `ss`، `ip`، `du`/`df`، `journalctl`، وأصدقاؤها — تغطي غالبية عمل التحقيق والإدارة اليومي على Linux.
- فضّل الأنماط الآمنة: اقتبس المتغيرات، استخدم أنابيب مفصولة بصفر لأسماء الملفات، ارفع الامتيازات فقط حيث يلزم، وابنِ الأوامر المعقدة خطوة بخطوة.
