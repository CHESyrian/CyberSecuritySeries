# Track 1 · Stage 1.5 — Access Control and IDOR

## Learning objectives
- Explain vertical vs horizontal privilege issues
- Test object ID and role checks **inside the lab app only**
- Document authorization gaps with evidence

## Safety checkpoint
Use lab accounts only. Do not attempt access control tests on third-party SaaS.

## Practice
With two lab users, attempt to access another user’s object by ID change in a training app that allows it. Record request and response codes.

## Review
- Why must authorization be enforced server-side?
