# Phase-0 · Foundation Modules

These modules provide the absolute beginner foundations required before studying the main cybersecurity curriculum (Stages 1–9).

All content is conceptual and beginner-friendly. No actionable attack instructions are included.

## Module List

| File | Topic |
|------|-------|
| `01_computer_basics.md` | Computer architecture, CPU/RAM/Storage, OS & processes, files & privileges, users/groups, services & ports, client/server, virtual machines |
| `02_linux_system.md` | Filesystem, permissions, users/groups, processes, services, logs, SSH, Bash scripting |
| `03_windows_system.md` | Windows architecture, NTFS permissions, services, processes, Registry, Event Viewer, PowerShell, Active Directory |
| `04_networking.md` | OSI & TCP/IP models, IPv4/IPv6, MAC, ARP, DNS, DHCP, TCP/UDP, HTTP/HTTPS, TLS, SSH, FTP, SMTP, NAT, VLAN, Routing, Switching, Firewalls, VPN |
| `05_cybersecurity_basics.md` | CIA Triad, AAA, Least Privilege, Defense in Depth, Attack Surface, Threat Modeling, Vulnerability/Exploit/Risk, Controls, Logging/Monitoring, Web concepts (HTTP, Cookies, Sessions, JWT, CORS, CSRF, Same-Origin), common vulnerability classes (conceptual) |
| `06_red_team.md` | Reconnaissance → Enumeration → Scanning → Vulnerability discovery → Exploitation → Privilege Escalation → Persistence → Lateral Movement + tool categories (high-level only) |
| `07_blue_team.md` | Logs, SIEM, IDS/IPS, Endpoint Security, Incident Response, Threat Hunting, Malware basics, Detection Engineering |

## Recommended Order

1. Computer Basics  
2. Linux System  
3. Windows System  
4. Networking  
5. Cyber Security Basics  
6. Red Team (conceptual)  
7. Blue Team (conceptual)

After completing Phase-0 you will be ready for the main staged curriculum (Introduction → CIA Triad → … → Penetration Testing Methodology).

## Self-check / review checklist

Before Phase-1, confirm you can:
- [ ] Explain hardware vs software and what an OS does
- [ ] Use basic Linux and Windows navigation comfortably
- [ ] Describe IP, ports, and client–server at a high level
- [ ] State what cybersecurity is trying to protect (people, data, systems)
- [ ] Distinguish red-team vs blue-team *roles* (not attack steps)
