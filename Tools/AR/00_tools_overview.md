# نظرة عامة على الأدوات

يوثّق هذا المجلد **الأدوات بالاسم**: الغرض، شرح موجز، و**أمثلة استخدام آمنة للمختبر**.  
السكربتات التنفيذية تحت `Codes/`. الاستخدام النشط يقتصر على أنظمة تملكها في مختبر معزول.

| المرحلة | كيف تظهر الأدوات |
|---------|------------------|
| 0 / 1 | بالاسم والشرح؛ بلا وصفات هجوم على أنظمة حقيقية |
| 2 / 3 | عمل عملي في المختبر + سكربتات مرافقة |

## فهرس الأدلة

| الملف | الأدوات |
|------|---------|
| `01_packet_analysis_tools.md` | Wireshark، tshark، Scapy، tcpdump، ping |
| `02_host_and_shell_tools.md` | Bash، ss، ps، PowerShell، Get-WinEvent وغيرها |
| `03_recon_and_scan_tools.md` | Nmap، ping، مساعدات socket |
| `04_crypto_and_web_tools.md` | openssl، sha256sum، DevTools، ZAP/Burp |
| `05_soc_and_detection_tools.md` | سجلات المصادقة، SIEM مختبري، سكربتات الكشف |
| `06_infra_and_cloud_tools.md` | التقوية، التجزئة، CLI سحابة (مختبر/طبقة مجانية) |

الإنجليزية: `Tools/EN/`.

## السلامة
1. أهداف تدريب ضعيفة عمداً. 2. استبدل عناوين IP بشبكة **مختبرك**. 3. لا تمسح الإنترنت العام. 4. عند الشك — توقف.

ينتهي كل ملف موضوع بـ**سير عمل مختبري** عند الحاجة.
