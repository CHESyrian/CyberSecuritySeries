# Diagrams Index

Central collection of Mermaid diagrams used across the cybersecurity curriculum.  
All diagrams are educational, high-level, and intended for authorized learning only.

## How to use

- Open any `.md` file in a Markdown viewer that supports Mermaid (GitHub, VS Code, many static-site generators).
- Copy the fenced `mermaid` block into lessons or slides when needed.
- Diagrams are intentionally simple and uncluttered.

## Conventions

- Prefer `flowchart`, `sequenceDiagram`, or `graph` as appropriate.
- Keep labels short and consistent with lesson terminology.
- Always pair a diagram with a one-paragraph explanation in the same file.
